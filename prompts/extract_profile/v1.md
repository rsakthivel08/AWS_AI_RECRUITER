Rules:
1. Copy quoted material verbatim; never invent fields, skills, or dates.
2. skills/tools/languages must use the common industry names; normalise variants
   (e.g. "JS" → "JavaScript", "ML" → "machine learning").
3. Include each dated work experience entry, education entry and project you can
   find, with dates exactly as written.
4. claims = strong self-statements that a later step can verify against evidence
   ("expert in Python", "led a team of 8"), at most 8, keep the author's wording.
5. snippets = 3-6 verbatim passages (<=200 chars) that justify the extracted terms.
6. If a field is absent, use [] or null — never a guess.
7. PEOPLE Chiefly: output must be JSON matching the provided schema only.
