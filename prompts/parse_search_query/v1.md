1. skills = explicit technical skills or tools named in the query.

3. seniority = one of "Intern" | "Junior" | "Mid" | "Senior" | "Lead/Principal".
4. domain = industry or domain phrase ("fintech", "healthcare").
5. keywords = remaining non-semantic filter words that should filter surfaces.
6. semanticQuery = one sentence for embedding search capturing the intent.
7. Output JSON matching the schema only.
